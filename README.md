# 100 Days of Code - Python Projects

My journey through the 100 Days of Code Python course, building projects from scratch to strengthen my programming skills. Each project includes enhancements and additional features beyond the course material, demonstrating problem-solving and code optimization. This repository also serves as practice for version control with Git and GitHub.

## Projects

### Day 7: Hangman
A classic word-guessing game with multiple themed word banks (Classic Words, Movies, Songs). Players can guess letter-by-letter or attempt the entire word at once, with a visual hangman display tracking remaining lives.
- **Skills**: Functions, loops, dictionaries, input validation, game state management
- **Features**: Three selectable themes, quit confirmation system, guess history tracking, replay option, limited input validation attempts
- **File**: `day07_hangman/main.py`

### Day 10: Calculator
A command-line calculator with basic arithmetic operations and comprehensive input validation. Supports continuous calculations where the result becomes the first operand for the next operation.
- **Skills**: Functions, loops, user input validation, error handling
- **Features**: Chain calculations, operation history, input sanitization
- **File**: `day10_calculator_project/main.py`

### Day 11: Blackjack
A terminal-based Blackjack card game featuring realistic card values, dealer AI, and game statistics tracking. Includes proper ace handling (11 or 1) and natural blackjack detection.
- **Skills**: Functions, lists, dictionaries, game logic, error handling, score tracking
- **Features**: Running statistics (rounds played, wins, win streaks), proper Blackjack rules implementation, replay functionality
- **File**: `day11_blackjack/main.py`

### Day 14: Higher Lower
A social media follower comparison game where players guess which account has more followers. Features a progressively harder gameplay as items are removed from the pool to avoid repetition.
- **Skills**: Dictionaries, lists, data manipulation, score tracking, game loops
- **Features**: Auto-removal of used items, game completion when all items exhausted, exit confirmation system, input validation with attempt limits, replay option
- **File**: `day14_higher_lower/main.py`

### Day 15: Coffee Machine
A coffee machine simulator that manages resources (water, milk, coffee), processes coin payments, and dispenses drinks. Built with an organized data structure for easy maintenance and scalability.
- **Skills**: Dictionaries, global variables, nested data structures, loops, input validation, financial calculations
- **Features**: Resource management with units, refill functionality, comprehensive input validation, coin payment system with change calculation, inventory reporting
- **File**: `day15_coffee_machine/main.py`

## How to Run:

1. Clone this repository:
```bash
   git clone https://github.com/ressikan-cb/100-days-of-code.git
```

2. Navigate to a project folder:
```bash
   cd 100-days-of-code/day11_blackjack
```

3. Run the Python file:
```bash
   python main.py
```
